pi

CLI-first AI coding agent built in the Zero language. Modeled on pi-mono.

Quick start

# Build and run
cd apps/pi
zero run -- "list the files in src"

Subcommands

  • pi chat — one-shot prompt to the default provider.
  • pi tools list — list registered tools.
  • pi sessions list — list saved sessions under ~/.pi/sessions/.
  • pi sessions show <id> — print a saved session.
  • pi providers list — list registered providers.
