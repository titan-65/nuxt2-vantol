# Immutable

Package registry website for the monorepo's npm packages. Features a landing page, package listing, individual package pages, and a dedicated null-agent showcase.

## Features

- **Landing Page** — Hero with terminal animation, feature grid, and quick start code examples
- **Package Listing** — Browse all packages in the monorepo
- **Package Detail Pages** — Dynamic pages for each package with install instructions
- **null-agent Showcase** — Dedicated docs page with features, interfaces, and live terminal demo
- **Teal/Nature Design System** — Glassmorphism cards, rise-in animations, custom CSS variables
