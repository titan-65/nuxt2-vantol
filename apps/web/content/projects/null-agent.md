# null-agent

Interactive coding assistant library with multi-provider LLM support, 49 built-in tools, a rich terminal UI, developer accountability tracking, and proactive event-driven automation.

## Features

- **Multi-Provider LLM** — OpenAI, Anthropic, Google Gemini, OpenRouter, and Ollama with streaming
- **49 Built-in Tools** — File operations, shell, git (16 ops), search, AST manipulation, memory
- **Terminal UI** — Ink-based TUI with chat scrolling, mood-reactive ASCII face, and live status
- **Proactive Engine** — Event-driven automation with LLM interpreter, signal queue, and approval gates
- **Developer Accountability** — Activity tracking, goal management, daily reports, and pattern analysis
- **User Model** — Learns preferences, communication style, and stores corrections
- **Orchestrator** — Spawn parallel sub-agents for complex tasks
- **Memory & Persistence** — File-based conversation storage with full-text search
- **Four Interfaces** — Terminal UI, REPL, HTTP server, or one-shot CLI
