# env-check

Validates environment variables against a typed schema at startup with clear, actionable error messages. Works as both a library and a CLI tool.

## Features

- **Typed Schema Validation** — Define your env vars with TypeScript types
- **Clear Error Messages** — Know exactly which variable is missing or invalid
- **CLI and Library** — Use as a library in your app or as a standalone CLI
- **Zero Dependencies** — Lightweight with no external runtime dependencies
