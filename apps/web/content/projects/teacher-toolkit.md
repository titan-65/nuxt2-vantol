# teacher-toolkit

Grade calculation utilities for teachers. Calculate letter grades, GPA conversion, weighted averages, score curving, and class statistics.

## Features

- **Letter Grade Calculation** — Convert numeric scores to letter grades
- **GPA Conversion** — Map letter grades to GPA scale values
- **Weighted Averages** — Calculate weighted scores across assignments
- **Score Curving** — Apply curve adjustments to entire classes
- **Class Statistics** — Mean, median, standard deviation, and distribution
