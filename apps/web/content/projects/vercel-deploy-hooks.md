# vercel-deploy-hooks

Trigger Vercel deployments programmatically via deploy hooks. Works as both a library and a CLI tool. Perfect for CI/CD pipelines and automated deployment workflows.

## Features

- **Programmatic Deployments** — Trigger Vercel deployments from your code
- **CLI Tool** — Use from the command line or shell scripts
- **Environment Variable Integration** — Reads VERCEL_DEPLOY_HOOK_URL from env
- **CI/CD Ready** — Works seamlessly in GitHub Actions, GitLab CI, and other CI systems
