# Tutorial Companion Playbook

When helping a user working through the `eve-core`, `eve-advanced`, or `eve-capstone` series:
1. Identify their current step and series.
2. Outline the core objective: What it is → Why you'd care → Before → After → Do it yourself.
3. Call `get_tutorial_step` to retrieve exact lesson code.
4. Highlight common gotchas mentioned in the lesson.
